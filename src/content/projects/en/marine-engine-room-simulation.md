## Scope

My work in marine engine-room simulation combines physical-system understanding with mathematical modelling, software implementation, interface integration and validation.

The public portfolio intentionally stays at architecture and engineering-method level. Proprietary model equations, customer-specific configurations, internal source code and confidential project data are not published here.

## Engineering responsibilities

- Mathematical modelling of machinery and auxiliary-system behaviour.
- Integration of model parameters with technical user interfaces.
- Test-procedure preparation and validation of expected system responses.
- Installation, commissioning and system-integration support.
- Technical documentation and training workflows.

## Engineering approach

A simulator is useful only when its dynamic response is technically credible. I therefore treat each subsystem as a testable model: define inputs and states, model transitions, verify limits and interlocks, then validate the interface behaviour against the intended operating logic.

## Overview

This work focuses on translating real marine machinery and engine-room systems into interactive software models for training, engineering analysis and system understanding.

The core challenge is not only reproducing a graphical interface. A useful engineering simulator must represent relationships between equipment, operating states, control logic, alarms, process variables and user actions in a coherent dynamic model.

## Engineering scope

Typical areas of investigation include:

- propulsion and auxiliary machinery
- fuel, lubrication and cooling systems
- electrical generation and distribution
- pumps, valves and process control
- alarm and safety logic
- operating procedures and fault scenarios
- real-time parameter relationships

## Development approach

My workflow starts with technical documentation and system research, continues with mathematical and logical modelling, and ends with interface integration, testing and validation.

Selected implementation details and reusable tools may be published separately when they are suitable for open-source release.

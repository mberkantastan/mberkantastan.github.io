# M. Berkan Taştan — Engineering Portfolio

Personal engineering, research and open-source portfolio built with Astro 6, TypeScript and Tailwind CSS 4.

## Requirements

- Node.js 22.12.0+
- npm

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Astro.

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This repository is configured for the special GitHub Pages repository name:

`mberkantastan.github.io`

In GitHub:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions**.
3. Push to `main`.

The included workflow will build and deploy the site.
